# VAAYU Product Issues Register

This is the full list of issues, gaps, errors, and structural problems found in the survey.
Each item says how it was verified. "Verified" means I reproduced it with a request or read the code
path. "Found" means it is from code reading and still needs a test. Severity:

- **Critical**: exploitable now, or can destroy data. Fix before any public traffic.
- **High**: serious security, data, or correctness risk. Fix before launch.
- **Medium**: correctness, structure, or operability problem. Fix before scale.
- **Low**: hygiene or polish.

## E. Things I have not yet checked

These are real gaps in my knowledge, not yet tested:

- Behaviour when Redis or PostgreSQL fails mid-request.
- Concurrent dispatch (two drivers accepting one trip).
- The customer booking flow in the browser, end to end.
- Merchant, fleet, and admin screens with real data.
- Mobile and responsive layout, accessibility.
- Whether rate limits are applied to every write route.
- Log content: whether logs can contain phone numbers, OTPs, or tokens.
